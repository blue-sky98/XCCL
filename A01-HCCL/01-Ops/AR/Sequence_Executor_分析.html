CCL Buffer 切分与使用

3.1 CCL Memory 整体划分

OrchestrateLoop（line 170-174）将 cclMem 平分为两半，分别作为 CCL-IN（scratch buffer）和 CCL-OUT（中间结果存储）：

CCL-IN（前半）— Scratch Buffer
• 起始地址：cclMem.addr
• 大小：cclMem.size / 2
• 用途：各模板的 hcclBuff，串行复用
• T0：RS 中间收发缓冲
• T1：DPU RS scratch
• T2：NHR AllGather 工作区（LocalCopy 写入，PostCopy 读出）
• T3：AG 中间收发缓冲
CCL-OUT（后半）— 中间结果存储
• 起始地址：cclMem.addr + cclMem.size / 2
• 大小：cclMem.size / 2
• 用途：跨模板的中间结果传递
• T0 输出：框内 RS 归约结果（chunk2）
• T1 输入/输出：框间 RS 原地操作（sub1）
• T2 输入/输出：框间 AG 原地操作（完整 chunk2）
• T3 输入：框内 AG 数据源 → usrOut

3.3 单次循环最大数据量（maxCountPerLoop）

maxCountPerLoop = hcclBuff.size / 2 / HCCL_MIN_SLICE_ALIGN × HCCL_MIN_SLICE_ALIGN / dataTypeSize_
其中 hcclBuff = cclInMem，其 size = cclMem.size / 2，因此：
maxCountPerLoop = (cclMem.size / 2) / 2 / align × align / dataTypeSize = cclMem.size / 4 / align × align / dataTypeSize
loopTimes = ⌈dataCount / maxCountPerLoop⌉，最后一轮处理尾块 dataCount - processedDataCount。 HCCL_MIN_SLICE_ALIGN 对齐保证 DMA 传输的地址对齐要求。

3.4 SplitData 切分逻辑（line 417-458）

SplitData(dataCount, rankSize, tempAlgParams) 将数据按 rank 数切分，采用 RoundUp 对齐 + 末尾余量策略：

切分公式
sliceCount = RoundUp(dataCount, rankSize)
sliceSize = sliceCount × dataTypeSize
// 前 rankSize-1 个 slice 等大
// 最后一个 slice = dataCount - (rankSize-1) × sliceCount
输出三个数组
• allRankSliceSize：每个 rank 的 slice 字节大小
• allRankProcessedDataCount：每个 rank 的 slice 元素数
• allRankDispls：每个 rank 的起始偏移（字节）
切分复用关系： T1/T2 复用 T0 的 allRankDispls/sliceSize/processedDataCount（框内切分结果）； T3 复用 T0 的切分结果。T1 内部再调用一次 SplitData 做框间切分（chunk2 → 4 sub）， T2 直接复用 T1 的框间切分结果（line 334-336）。
